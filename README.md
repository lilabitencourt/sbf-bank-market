# Bank Marketing Propensity Model (Professional Version)

Projeto completo com:
- Separação treino/teste
- Pipeline com padronização
- Validação cruzada (5-fold)
- GridSearch para seleção de hiperparâmetros
- Avaliação com AUC
- Salvamento do melhor modelo

## Como rodar

Coloque o dataset em:

data/raw/bank-full-case.csv

Depois execute:

pip install -r requirements.txt
python main.py
